# Beauty & Wellness Interactive Excel Dashboard

## Project Overview

This project is an interactive Excel dashboard developed for beauty and wellness business analytics. The dashboard transforms cleaned sales and customer data into meaningful visual insights that can support business monitoring and decision-making.

## Objectives

- Analyze overall sales performance
- Monitor customer engagement
- Compare product performance
- Analyze customer segments
- Evaluate sales by city and channel
- Track monthly sales trends
- Provide interactive filtering using slicers
- Present key business KPIs in a management dashboard

## Key Features

- Interactive Excel dashboard
- KPI cards
- PivotTables
- PivotCharts
- Slicers
- Conditional formatting
- Customer segmentation
- Product performance analysis
- City and channel analysis
- Monthly sales analysis
- Advanced Excel functions such as INDEX and MATCH

## Key KPIs

- Total Sales
- Total Orders
- Average Order Value
- Total Quantity
- Average Customer Rating
- Highest Sale

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Conditional Formatting
- Excel Functions
- Data Cleaning and Analysis

## Dataset

The project uses a beauty and wellness business dataset containing information such as order details, dates, cities, products, categories, customer demographics, sales, quantity, sales channels, payment modes, and ratings.

## Project Deliverables

1. Interactive Excel Dashboard
2. Task 4 Project Report
3. Data analysis and visualization

## Conclusion

The dashboard provides an interactive way to explore beauty and wellness business data and identify patterns in sales, products, customers, cities, and monthly performance. It demonstrates practical skills in Excel-based data cleaning, analysis, visualization, dashboard development, and business reporting.
